# agent-sdk pimo — site

The public page for **agent-sdk pimo**, a private, local-first agent SDK and
runtime.

This repository is the *presentation layer only*. It contains one
self-contained HTML file with its CSS inlined: no fonts, no trackers, no CDNs,
no build step, and no data of any kind. There is nothing here to leak.

The implementation is not public. It is a private repository; this page
describes what the runtime guarantees and how to install it locally. Nothing
about the private source, your machine, or your configuration is published
here.
